알루미늄 TIG 용접 자료조사
분류 구조 및 구성안
구분	내용
재질	Aluminum (알루미늄)
공정	Pipe TIG Welding (파이프 TIG 용접)
자세	1G / 2G / 5G / 6G
작업 단계	Fit-up (배관 맞춤 및 고정 작업) / Root Pass (첫 내부 용접층 작업) / Fill Pass (중간 채움 용접 작업) / Cap Pass (마지막 표면 마감 용접 작업)
숙련 포인트	열제어 / 용입 / 산화막 관리 / 와이어 공급 / 비드 유지


① Aluminum 1G TIG
특징

파이프를 돌릴 수 있는 가장 기본적인 자세임.
작업자가 편한 자세로 용접할 수 있어서 TIG 용접 입문이나 기본 연습 때 가장 많이 사용함.
알루미늄 TIG에서 가장 중요한 아크 길이 유지와 와이어 넣는 타이밍을 연습하기 좋음.

핵심 학습 포인트
AC 밸런스 유지 : 알루미늄 표면 산화막 제거와 용입 균형 맞추기
산화막 확인 : 표면이 깨끗해야 정상 용접 가능
용융풀(Puddle) 관찰 : 녹는 범위를 계속 눈으로 확인
과열 방지 : 오래 한 곳 보면 금방 퍼짐
비드 일정하게 유지 : 용접 자국 폭이 균일해야 함

② Aluminum 2G TIG
특징

파이프가 세로 방향으로 고정된 상태에서 작업하는 자세임.
파이프를 돌릴 수 없어서 작업자가 직접 손을 움직이며 용접해야 함.
중력 영향을 많이 받아 아래쪽 비드가 처지기 쉬움.

핵심 학습 포인트
중력 때문에 녹은 금속이 아래로 흐르는 현상 대응
하단부 비드 처짐 방지
와이어 공급 타이밍 조절
좌우 비드 균형 유지

③ Aluminum 5G TIG
특징

파이프가 가로로 고정된 상태에서 용접하는 자세임.
현장에서 실제 배관 작업할 때 많이 나오는 방식임.
작업하면서 위, 옆, 아래 자세가 계속 바뀌기 때문에 난이도가 높아짐.

핵심 학습 포인트
자세 바뀔 때 토치 움직임 유지
손목 각도 일정하게 유지
오버헤드(천장 방향) 구간 대응
루트패스 안정적으로 유지

④ Aluminum 6G TIG
특징

파이프가 대각선으로 고정된 최고 난이도 자세임.
모든 방향 자세가 한 번에 포함되어 있어서 실제 숙련도를 가장 많이 요구함.
플랜트나 산업 배관 시험에서도 자주 사용됨.

핵심 학습 포인트
계속 바뀌는 자세 적응
열 누적 관리
손목 이동 숙련
비드 모양 일정하게 유지
